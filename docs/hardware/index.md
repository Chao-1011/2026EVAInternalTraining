# 拆装前检查

本页仅整理大致流程，具体拆装步骤见[更换硅脂与加装硬盘、内存](upgrades.md)。

## 维修准备

- [ ] 完成登记与工单，确认机主希望处理的问题。
- [ ] 开机检查，记录已有故障与设备状态。
- [ ] 确认重要资料已备份，检查机型、保修情况及拆装方式。
- [ ] 关机、拔掉外部电源，拆开后盖后断开内置电池。
- [ ] 按位置整理螺丝，保留排线与部件位置记录。

## 按问题确定解决方案

!!! warning "液金与导热材料"

    协会不拆使用液金散热的笔记本散热模组。先确认机型与散热方案。在**更换硅脂**前一定要询问机主电脑是否为液金散热，如果是液金的电脑千万不要拆散热模组！！

    - 常见的液金散热的笔记本：ROG（特别是红色主板）


## 装回与检查

- [ ] 检查风扇、屏线等排线是否恢复连接。
- [ ] 装回部件与螺丝，确认没有遗漏。
- [ ] 恢复电池连接，装好后盖，检查正常开机。
- [ ] 检查新增硬盘、内存是否识别，并检查本次维修涉及的功能。
- [ ] 记录处理结果，向机主说明完成情况。
