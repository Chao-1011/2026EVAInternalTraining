# 更换硅脂与加装硬盘、内存

本指南面向 EVA 维修成员，说明笔记本电脑更换硅脂、加装或更换 M.2 硬盘、加装或更换可拆卸内存的完整流程。先完成共同的准备与断电步骤，再选择对应任务，最后装回并验收。

不同机型的后盖卡扣、排线接口、螺丝顺序和散热材料可能不同。**实际拆装以对应型号的维修手册为准**，文中配图用于认识部件与操作界面。

| 本次任务 | 从哪里开始 | 完成后检查 |
| --- | --- | --- |
| 更换硅脂或相变片 | [散热维护](#thermal-service) | 风扇运转、温度表现、稳定性 |
| 加装或更换 M.2 硬盘 | [硬盘安装](#ssd-installation) | 硬盘识别、分区、文件读写 |
| 加装或更换内存 | [内存安装](#ram-installation) | 总容量、正常启动、运行稳定性 |
| 多项任务一起做 | 先阅读全部任务，再统一拆机 | 每项任务分别验收 |

## 一、维修前准备

### 确认任务与设备状态

1. 完成登记与工单，记录电脑品牌、完整型号和机主描述的问题。
2. 开机检查，记录原有故障、内存容量、硬盘型号与容量。处理散热问题时，记录当前风扇是否有异响，以及同一测试条件下的温度表现。
3. 确认机主允许本次拆装，询问保修情况。遇到易碎贴或封条时，先核对该机型的保修与维修说明。
4. 确认重要资料已备份。更换系统盘前，确定是迁移旧系统还是安装新系统，参考[重装系统指南](../maintenance/reinstall.md)。
5. 查询对应型号的维修手册，确认后盖打开方式、电池接头、散热方案、可用硬盘槽位及内存规格。

!!! warning "液金机型的处理范围"

    协会不为液金散热笔记本更换液金，也不拆其散热模组。液金泄漏可能造成短路与部件损坏。

    询问机主后，还需按完整型号与配置核实散热方案。品牌、主板颜色只能作为线索；无法确认时，停止散热模组拆卸，联系有经验的成员。可以进行的清灰项目也应先确认不会扰动液金部位。

### 准备工具与材料

| 工具或材料 | 用途与检查点 |
| --- | --- |
| 匹配规格的螺丝刀 | 刀头应与螺丝贴合，避免滑丝 |
| 塑料撬片 | 打开后盖卡扣，避免用金属工具碰到主板 |
| 螺丝盘或分区收纳盒 | 按位置保存螺丝，区分长度及型号 |
| 防静电用品 | 按维修手册进行静电防护，拿部件时握边缘 |
| 软刷、气吹 | 清理风扇与散热鳍片 |
| 适合电子部件的酒精清洁用品、无绒擦拭材料 | 清除核心及导热片上的旧硅脂，避免液体流入接口 |
| 硅脂与刮刀，或适配的相变片 | 更换核心导热材料 |
| 兼容的新硬盘、内存及固定件 | 安装前核对规格，硬盘固定螺丝应适配机型 |
| 备份设备 | 保存需要保留的数据 |

只做硬盘或内存升级时，无需拆散热模组或准备更换硅脂。

### 关机、开后盖与断电

1. 正常关闭系统，确认电脑已关机。
2. 拔掉电源适配器、U 盘及其他外接设备，等待高温部件冷却。
3. 按维修手册拆下后盖螺丝，记录每颗螺丝的位置与长度。
4. 沿指定位置用塑料撬片打开卡扣。若后盖仍被固定，检查隐藏螺丝或未松开的卡扣。
5. **在接触风扇、散热模组、硬盘或内存之前，断开内置电池。**先识别电池接头的锁扣和拔出方向，按维修手册操作，避免拉扯线材。
6. 按该机型要求完成剩余电量释放与静电防护，拍照记录排线、部件和螺丝位置。

!!! warning "阻力异常时先停手"

    螺丝、后盖、排线或插槽出现明显阻力时，先检查锁扣、拆卸方向和隐藏固定件。不要强撬、强拔或反复加力。电池鼓包、漏液或部件有烧损痕迹时，停止普通拆装并交由有经验的成员处理。

## 二、更换硅脂与相变片 { #thermal-service }

### 认识散热模组与导热材料

散热模组把 CPU、GPU 等芯片产生的热量传递到散热鳍片，再由气流带走。拆卸前应分清哪些是核心导热材料，哪些是显存及供电区域的填充材料。

| 部件或材料 | 作用 | 本次操作 |
| --- | --- | --- |
| CPU / GPU 核心 | 产生热量，与导热片接触 | 清洁旧材料，重新铺设适配材料 |
| 导热片 | 与核心接触，接收热量 | 清洁对应接触面上的旧硅脂 |
| 热管 / 均热板 | 传导并分散热量 | 避免弯折、划伤或受力变形 |
| 散热鳍片 | 增加散热面积 | 清除缝隙中的灰尘 |
| 风扇 | 形成气流 | 按任务需要拆装及清灰 |
| 导热垫 / 导热凝胶 | 填充显存、供电等部件与散热模组之间的间隙 | 保持原位置与完整性，不能随意换成核心硅脂 |

![笔记本散热模组示例，可观察热管、鳍片和风扇的位置](../assets/ppt/upgrades/bec7b794594990bd.png){ loading=lazy }

### 第 1 步：确认螺丝与排线位置

拆前先判断散热模组能否单独取下，是否需要先拆风扇，以及有没有覆盖螺丝的膜、散热片或绕过风扇的排线。

- 检查导热片附近的弹簧螺丝与数字标记。
- 检查热管弯折处、覆盖膜下方及风扇边缘的固定螺丝，避免漏拆。
- 区分普通固定螺丝与防脱螺丝；防脱螺丝松开后留在模组上，不能强行取出。
- 如需揭开覆盖膜，先确认允许拆卸，并记录原位置。

![散热模组覆盖膜与固定位置示例](../assets/ppt/upgrades/dde3eb5ec6cb8ebb.jpeg){ loading=lazy }

!!! note "不必要的排线可以保留连接"

    部分机型可以保留风扇与屏线，只拆散热模组。若屏线挡住拆卸路径，先查该机型的接头结构与拆法，不要照搬另一机型的拔线方向。

??? info "查看特殊机型的排线路径示例"

    原课件以部分暗影精灵机型说明屏线绕过风扇、热管遮挡固定位置等情况。不同年份与配置可能不同，请按实际结构判断。

    ![排线绕过风扇的机型示例](../assets/ppt/upgrades/4058b0c94781f8e8.png){ loading=lazy }

    ![散热模组周围的结构示例](../assets/ppt/upgrades/c4c932467dcc39ea.png){ loading=lazy }

### 第 2 步：按需要拆卸风扇并清灰

1. 在已经断开电池的情况下，记录风扇排线的位置与方向。
2. 按接口结构断开风扇接头，避免直接拉扯线材。
3. 拆下固定螺丝，检查是否有排线借助风扇外壳固定。
4. 移开相关排线后取下风扇。只需清灰时，拆到能清洁风扇与风道即可，避免继续拆开胶封或小螺丝封装的风扇本体。
5. 用软刷清理灰尘，再清理散热鳍片缝隙。使用气吹时固定扇叶，避免让风扇高速空转。

![风扇周围的排线位置示例](../assets/ppt/upgrades/48a2e524a0ab49f7.jpeg){ loading=lazy }

![风扇与散热模组的固定关系示例](../assets/ppt/upgrades/869de64495d7d9d5.jpeg){ loading=lazy }

### 第 3 步：拆下散热模组

1. 以维修手册中的拆卸顺序为准。原课件中标有装配数字的示例采用“拆卸逆序、装配顺序”，使用前应确认数字含义。
2. 分多轮逐步松开螺丝，让各固定点均匀释放压力。不要先把某一颗完全卸下，再处理其余螺丝。
3. 确认所有固定点已松开、相关排线已移开，再轻轻抬起模组。
4. 如果旧硅脂使导热片与核心粘连，先检查是否仍有固定件；允许时轻微晃动以帮助分离，避免掰弯热管或撬压核心。
5. 若仍无法取下，停止操作，查阅机型手册或请有经验的成员协助。不要在散热模组已经松动或拆开的状态下通电加热。

![散热模组螺丝旁的数字标记示例](../assets/ppt/upgrades/56d1266d70d3b928.jpeg){ loading=lazy }

### 第 4 步：清除核心与导热片上的旧硅脂

1. 确认 CPU、GPU 核心的位置，拍照保存显存及供电区域导热材料的状态。
2. 用适合电子部件的清洁用品和无绒材料，轻轻擦除核心表面的旧硅脂。
3. 清洁散热模组上与核心接触的导热片，避免残留硅脂影响贴合。
4. 检查是否有掉落的碎屑、残留纤维或多余液体，待清洁区域充分干燥后再安装。

!!! warning "保留显存和供电区域的导热材料"

    白色、粉色或蓝色材料可能是导热凝胶或导热垫。不要按清除核心硅脂的方式把它们擦掉。若材料已经移位、破损或缺失，先确认所需规格与厚度，再处理；不能随意叠加或用普通硅脂填补间隙。

![CPU、GPU 核心与周围显存区域示例](../assets/ppt/upgrades/1ff6d539383f2c22.png){ loading=lazy }

![导热片接触面上的旧硅脂残留示例](../assets/ppt/upgrades/12d27bbc040d589e.jpeg){ loading=lazy }

### 第 5 步：铺设新的导热材料

#### 方案 A：硅脂

原内训使用信越 7921 / 7868。实际使用前，确认材料适合该机型及接触面。

1. 在 CPU、GPU 核心上分别取适量硅脂。可按课件方法沿核心一侧放一条，再用刮刀轻轻铺开。
2. 在裸露核心上形成均匀、薄且连续的覆盖层，覆盖需要接触导热片的区域。
3. 检查有无明显漏涂、厚块或外溢。涂抹量应足以覆盖接触面，避免大量堆积。
4. 使用后盖好硅脂容器，擦净刮刀。

![原课件使用的硅脂示例](../assets/ppt/upgrades/9a436d11d44fa2cd.jpeg){ loading=lazy }

#### 方案 B：相变片

原课件介绍了 PTM7950 相变片。相变片应按材料说明及机型要求使用，其效果取决于接触压力、安装质量和散热设计。

1. 确认核心接触面尺寸，裁剪适配大小，避免覆盖周围元件。
2. 按材料说明去除保护膜，铺到目标接触面。
3. 检查另一面是否仍有保护膜，安装散热模组前去除需要揭下的膜。
4. 保持材料平整，避免折叠、堆叠或在其上再叠加硅脂。

![相变片及易撕贴的原课件示例](../assets/ppt/upgrades/89e47edd7d5cfc2c.jpeg){ loading=lazy }

### 第 6 步：装回散热模组与风扇

1. 检查核心、导热片和周围导热材料，确认接触面清洁、材料位置正确。
2. 如果风扇位于热管下方，先按原位置装回风扇。
3. 对齐散热模组与固定孔，平稳放下，避免在核心表面反复拖动。
4. 按维修手册规定的顺序和扭矩固定螺丝。没有扭矩工具时，不要凭力气过度拧紧；需要具体数值时先查手册。
5. 弹簧螺丝分多轮均匀拧紧，避免某一侧先压到底。
6. 恢复风扇及本次断开的其他排线，检查线材没有被热管、外壳或螺丝夹住。
7. 完成[装回与验收](#final-check)。

## 三、加装或更换 M.2 硬盘 { #ssd-installation }

### 第 1 步：确认槽位、规格与用途

硬盘用于长期存储系统、软件及个人文件。安装前先确认“加装数据盘”还是“替换已有硬盘”，两者后续处理不同。

| 检查项目 | 需要确认的内容 |
| --- | --- |
| 可用槽位 | 是否有空槽，是否需要拆下散热片；不要假定所有游戏本都有两个槽位 |
| 长度与固定位置 | 例如 M.2 2280 表示宽 22 mm、长 80 mm，机型需提供对应固定位置 |
| 接口与协议 | 按机型手册核对支持的硬盘协议及接口，不能仅凭外形相似判断兼容 |
| 安装空间 | 单双面硬盘、散热片及导热垫是否与机内空间匹配 |
| 固定件 | 螺丝和支撑柱是否齐全、位置正确，避免用不适配的螺丝代替 |
| 原盘数据 | 替换系统盘前完成备份，确定迁移或重装方案；旧盘妥善保存 |

![硬盘槽位与散热片的机内示例](../assets/ppt/upgrades/07c5b08b32705603.png){ loading=lazy }

![另一种硬盘安装区域示例](../assets/ppt/upgrades/d4fe11c5c99883e2.jpeg){ loading=lazy }

### 第 2 步：拆下旧盘或槽位散热片

1. 确认电池已经断开。
2. 如有散热片，记录导热垫位置，拆下固定螺丝，再移开散热片。
3. 替换旧盘时，松开硬盘固定螺丝，扶住盘体，允许其自由端轻微抬起。
4. 沿插槽方向把旧盘平稳拔出，握住边缘，避免触碰金手指。
5. 保存旧盘及原固定件，检查槽位内是否有异物或损伤。

螺丝过紧或已经滑丝时，停止反复拧动，换用正确刀头或请有经验的成员处理。

### 第 3 步：插入并固定新盘

1. 对准金手指缺口与插槽方向。
2. 按接口结构，以适当倾斜角度插入。原课件示例约为 15°–30°，角度应以实际槽位为准。
3. 确认金手指已充分插入后，将自由端轻轻压向固定位置。
4. 固定螺丝应对准支撑柱，拧到盘体稳定即可，避免让盘体弯曲。
5. 按原位置恢复导热垫与散热片，确认没有夹住排线。
6. 装回电脑后，在 BIOS / UEFI 或系统中确认硬盘被识别。

![M.2 插槽与接口示例](../assets/ppt/upgrades/7bada0c2616cd9c0.png){ loading=lazy }

![M.2 硬盘的尺寸与长度示例](../assets/ppt/upgrades/47f0b378b71c6118.jpeg){ loading=lazy }

!!! note "系统盘更换后不能直接启动的情况"

    空白新盘没有原系统。若更换的是系统盘，应按事先确认的迁移或重装方案继续处理；仅安装硬盘并不会自动复制原有系统。

### 第 4 步：判断是否需要初始化

新硬盘已经安装，但文件资源管理器里没有显示，不一定意味着没有识别。打开“磁盘管理”，先看设备状态。

| 磁盘管理中的状态 | 下一步 |
| --- | --- |
| 确认是全新空盘，显示未初始化 | 核对目标盘后初始化，再创建分区 |
| 已初始化，有未分配空间 | 在确认为空白目标区域后创建简单卷 |
| 已有正常分区，只是没有盘符 | 确认分区用途后分配可用盘符，保留数据 |
| 旧盘突然显示未初始化、RAW 或异常 | 停止写入，先排查连接和数据状态 |
| 磁盘管理中完全看不到 | 关机断电后复查连接、接口兼容性与 BIOS 识别情况 |

!!! warning "初始化与格式化的对象必须确认"

    下面的步骤只适用于已确认没有需要保留数据的新盘。旧盘或来源不明的硬盘即使显示“未初始化”，也不能直接照做。不要把原系统盘、备份盘或恢复分区当作新盘处理。

### 第 5 步：初始化全新空盘

1. 右击 Windows 开始按钮，打开 **磁盘管理**；也可以搜索“创建并格式化硬盘分区”。
2. 根据硬盘容量、型号等信息确认新盘，核对磁盘编号。必要时打开磁盘属性进一步确认。
3. 对确认的空盘选择 **初始化磁盘**。
4. 现代 Windows 电脑通常选择 **GPT**；有旧系统或特殊兼容要求时，先按实际环境确认。
5. 完成后，应看到该盘的 **未分配** 空间。

初始化只建立分区结构，后面还需要创建卷与分配盘符。操作范围与步骤可参照 [Microsoft：初始化新磁盘](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/initialize-new-disks)。

### 第 6 步：新建简单卷并分配盘符

1. 在新盘的 **未分配** 空间上右击，选择 **新建简单卷**。
2. 确认机主需要一个分区还是多个分区。单分区可以使用默认最大容量；多个分区则先分配本次需要的大小。
3. 选择一个可用盘符，避免与已有设备或固定的软件路径冲突。
4. 用于常规 Windows 内置数据盘时，文件系统通常选择 **NTFS**，分配单元大小保留默认值，填写容易识别的卷标。
5. 再次核对目标盘、卷大小及格式化选项，确认后完成向导。
6. 打开文件资源管理器，检查盘符与容量，再创建一个测试文件并读取，确认可以正常使用。

!!! note "扩容已有分区需要另行判断"

    新建分区与扩大已有分区是不同任务。Windows 磁盘管理扩展常见基本卷时，需要同一磁盘上紧邻目标分区右侧的未分配空间，且文件系统满足要求。不能把另一块新硬盘的容量直接加入原来的 C 盘，也不能把“扩展卷”当作任意合并分区的方法。

    具体限制见 [Microsoft：扩展卷](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/extend-a-basic-volume)；C 盘空间处理见[C 盘清理与扩容](../maintenance/c-drive.md)。

## 四、加装或更换内存 { #ram-installation }

内存用于保存系统当前运行的数据，断电后内容不会保留。加大内存容量可以改变可用运行空间，但不会增加保存文件的硬盘容量。

![笔记本内存部件示例](../assets/ppt/upgrades/8166171823a1329b.png){ loading=lazy }

### 第 1 步：确认可以升级及规格兼容

1. 查维修手册，确认是否有可拆卸内存槽。板载内存不能按本指南拔下更换。
2. 核对内存代际、模块形式、单条容量与整机最大支持容量，避免只按外观选购。
3. 确认空槽数量及新内存与现有配置的兼容性，多个槽位按手册要求选择安装位置。
4. 记录升级前的总内存容量与已安装模块，便于装回后核对。

### 第 2 步：取下旧内存

1. 确认电脑已经关机，电源适配器和内置电池均已断开。
2. 按机型要求打开内存区域的屏蔽罩或保护膜，保留固定件。
3. 轻轻向两侧拨开金属卡扣，让内存条自行弹起。
4. 握住内存条两侧，沿插槽方向拔出，避免触碰金手指。
5. 如果内存没有弹起，检查两侧卡扣是否都已释放，不要直接向上掰。

### 第 3 步：插入新内存

1. 对准内存金手指缺口与插槽凸起，确认方向。
2. 以接口允许的角度插入，原课件示例约为 15°–30°。
3. 确认金手指充分插入后，均匀压下内存条自由端，使其落入两侧卡扣。
4. 检查两边卡扣均已锁定、内存条平稳且没有翘起。不能仅凭一声“咔嗒”判断安装完成。
5. 恢复保护膜或屏蔽罩，再完成装回与验收。

## 五、装回与验收 { #final-check }

### 通电前检查

- [ ] 散热模组、硬盘、内存和风扇均已固定，机内没有遗留螺丝或工具。
- [ ] CPU / GPU 导热材料已正确铺设，导热垫与凝胶位置没有遗漏。
- [ ] 风扇排线、屏线及本次断开的其他接头均已恢复。
- [ ] 排线未被热管、螺丝、后盖或卡扣挤压。
- [ ] 确认内部操作结束后，按手册恢复电池连接。
- [ ] 装回后盖与螺丝，螺丝长度与原位置一致。

### 按任务验收

| 任务 | 检查方法 | 发现异常时 |
| --- | --- | --- |
| 所有拆装任务 | 检查正常开机、屏幕、键盘及本次动过的接口 | 关机断电，复查相关排线与连接 |
| 换硅脂或相变片 | 先观察待机与风扇，再在与维修前相同的条件下逐步增加负载，比较温度与噪音 | 温度迅速异常上升、风扇异常或自动关机时立即停止测试 |
| 加装数据盘 | 检查型号、容量、盘符与文件读写 | 先区分未识别、未分区或盘符问题，避免直接格式化 |
| 更换系统盘 | 检查系统启动与原计划中的数据恢复情况 | 复查启动设备与迁移或安装结果 |
| 加装内存 | 在 BIOS / UEFI 或任务管理器中核对总容量，按需要运行内存诊断 | 关机断电后检查卡扣、插入状态及兼容性 |

**不要用统一温度数值判断所有机型是否合格。**记录环境、负载和测试条件，结合对应机型的正常表现判断；散热模组未装好时禁止开机或压力测试。

### 记录并交付

记录本次处理的部件、使用材料、新硬盘或内存型号与容量、测试结果，以及需要机主继续关注的问题。旧部件与机主数据按约定归还或保存，说明新增盘符和分区用途。

## 六、常见问题排查

| 现象 | 优先检查 | 避免的操作 |
| --- | --- | --- |
| 模组抬不起来 | 隐藏螺丝、覆盖膜、粘连材料、挡住的排线 | 用金属工具撬核心或强行掰热管 |
| 风扇不转或有异响 | 风扇排线、固定状态、线材是否碰到扇叶 | 长时间烤机验证未装好的风扇 |
| 换硅脂后温度明显异常 | 接触面、覆盖范围、模组贴合、导热材料和螺丝压力 | 继续提高负载观察是否自行恢复 |
| 新盘在资源管理器中看不到 | BIOS 与磁盘管理的识别状态、分区及盘符 | 对所有“未初始化”磁盘直接初始化 |
| 装内存后不开机或容量不对 | 插入深度、两侧卡扣、规格与安装位置 | 带电重插或强压不兼容的模块 |
| 螺丝无法松开 | 刀头规格、是否为防脱螺丝、是否滑丝 | 反复加力导致螺丝或主板损坏 |

复查内部连接前，重新执行关机、断开适配器与内置电池的步骤。无法明确判断原因时，保留现场记录并请有经验的成员协助。
