## 按维修问题查找

!!! info "疑难杂症 ⚠️"

    电脑问题很难通过内训实现全覆盖，很多问题需要具体问题具体分析。碰到不会或者没有把握的内容请及时询问在场的学长或者有经验的同学。切忌没有把握直接进行危险操作。

| 遇到的问题 | 推荐资料 |
| --- | --- |
| C 盘空间不足、软件或缓存占用太多 | C 盘清理与扩容 |
| 无法进入原系统，需要启动维修环境 | PE 盘的使用 |
| 系统损坏或新硬盘需要安装系统 | 重装系统 |
| 需要更换硅脂、加装硬盘或内存 | 清灰换硅脂 |

## 学习顺序

!!! note "资料使用"

    内训课程以及PPT后续都会发在QQ工作群内，可以自行下载。也可以看该网页的内容。

1. 学习拆装前检查，熟悉登记工单、开机检查与断电要求。
2. 学习清灰与更换硅脂，认识硬件与拆装流程。
3. 学习加装硬盘、内存，认识硬件与更换流程。
4. 学习 PE 盘的使用，认识维修环境 WinPE 和常用工具。
5. 学习C 盘清理与扩容，了解数据迁移。
6. 阅读重装系统流程，熟悉数据备份与系统设置。
7. 进一步学习系统迁移，解决硬盘空间不足。
